## 市场与图表

市场页默认列出币安可交易的 USDT 现货交易对，按 24 小时成交额排序；可搜索币种或完整交易对、切换报价币，并将常看币种加入本机自选。公开行情使用币安的 `data-api.binance.vision`，无需账户密钥。目录刷新失败时会标出旧目录；首次无法取得目录时显示未核验的常见候选，请勿将其视为已确认可交易。

点击列表加载行情，可切换 15 分、1 小时、4 小时、日线，以及 K 线或折线。图表支持拖动、滚轮缩放和快捷缩放；下方时间轴可拖动两端选择研究区间，或用 7/30/90/365 天快捷档与自定义日期。日期均按 UTC，结束日期不含当天。拖动时间轴会同步日期输入和策略回测的区间；如果交易对上市较晚、历史不足，请选更短的日期范围。

当前交易对的“实时盘口”使用币安公开现货 WebSocket，展示前 20 档买卖挂单，每秒推送一次；页面切换或浏览器标签隐藏时暂停，回来后重新连接。最优买卖价、价差和前 20 档买盘占比会随盘口更新。买盘占比按挂单的报价币名义金额计算，只反映这一时刻、这一交易所可见的限价挂单；挂单可撤销，不能当作已成交的资金流入。历史 K 线的结束日不含当天，实时盘口与历史图分别标示。最近 120 天内且不超过 1000 根的 K 线走一次公开 REST 请求，减少图表首屏等待。

三张小图显示当前收盘价相对 20 根前的涨跌、本根成交量相对前 20 根均量的倍数，以及当前价相对近 20 根最高收盘价的回撤。它们只来自现货 OHLCV 数据，不能证明资金流向、交易者身份或涨跌原因。

研究结论和历史回测都不是未来收益保证。真实交易功能默认关闭，并且每笔订单需要单独确认。

## 开源策略研究与模拟练习

策略实验室有 Freqtrade Strategies 的公开文件目录，每天轮换一条阅读候选。点击可打开固定 Git 版本的原仓库源码，并保存自己的学习笔记；目录缓存 6 小时。文件来自第三方 GPL-3.0 项目，本仓库只保存元数据和链接，不复制或执行策略源码。这些策略需要在独立 Freqtrade 环境中研究、回测；当前工作台内置回测器只支持页面列出的四种原生规则，不能直接运行 Freqtrade 的 Python 策略。

页面另附 Hummingbot `simple_pmm` + `binance_paper_trade` 的模拟练习命令，按[官方安装指引](https://hummingbot.org/installation/hummingbot-client/)在专用实例中运行。`hbot start` 会操作该实例的当前配置，启动前须核对仍为 paper connector。本工作台目前不安装、启动或控制 Hummingbot，也不从它读取账户密钥；模拟结果可先记入研究笔记。[接入研究与后续接口设计](docs/integrations/2026-09-27-open-strategy-engines.md)包含 Freqtrade、Hummingbot、币安和 OKX 的实施顺序。

钱包连接使用 MetaMask Connect（© ConsenSys Software Inc.）。它按[非商业许可](crypto_app/static/vendor/METAMASK-CONNECT-LICENSE)提供，本项目及其衍生版本使用该组件时均须遵守该许可和显著署名要求。前端依赖通过 `npm ci && npm run build:wallet` 构建；仓库保留本地构建后的脚本，运行时无需 npm。

资产页可合并查看币安现货余额与 Ethereum、BNB Smart Chain 钱包余额。钱包只需公开地址，可手动粘贴或通过 MetaMask Connect 选择。先用 `python3.12 -c 'from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())'` 生成主密钥，启动前将结果置于环境变量 `CRYPTO_MASTER_KEY`；在设置页录入仅有读取权限的币安 API Key 和 Secret。凭证只在本机加密保存，服务重启仍需同一主密钥。无可信新鲜价格的资产标为“未计价”，不会当作零估值；NFT、借贷债务等不在首版汇总范围。价格来自 CoinGecko 或币安公开行情，来源和时间在每项资产旁显示。

## 真实手动交易

真实交易默认关闭。所有者需要单独创建有现货交易和读取权限、**没有提现权限**的币安 API 密钥，并在币安侧限制可访问 IP。设置 `CRYPTO_MASTER_KEY` 后，在“设置”页面填写交易密钥、至少 12 字符的解锁口令、单笔和单日 USDT 限额。只读密钥与交易密钥存储在不同加密槽位。点击“立即停用真实交易”可关闭新订单；已提交订单仍须在币安核对。

“交易”页面只支持 USDT 报价的币安现货限价和市价买卖。填写交易对、方向、类型和基础币数量后，先获取有效期 30 秒的预览。预览显示估算金额、费用、滑点和限额，再输入解锁口令明确确认。取消订单也需再次输入口令。提交响应只是订单状态，不能视为成交；遇到网络超时显示“待核实”，只按原客户端订单 ID 查询，不自动重发。市场成交价可能偏离预览价，市价金额及费用上限是基于当前报价的预估，请在交易所核对最终成交。

本服务仅在 `127.0.0.1:8765` 监听，未实现公网登录认证。不要映射到局域网或公网。自动测试全部使用假交易所，不会发送真实订单；首次使用交易密钥时，请在币安侧仔细核对权限并自行逐笔确认。

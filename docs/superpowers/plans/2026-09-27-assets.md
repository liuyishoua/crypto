# 币安与链上资产汇总 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在市场研究工作台中按来源查看币安现货余额与 Ethereum、BNB Smart Chain 的钱包资产。

**Architecture:** 各资产源只返回数量和来源，独立价格适配器给出 USD 估值；聚合层保留未计价项和每项时间戳。币安只读密钥留在服务端加密存储，MetaMask 只提供公开地址，亦可手动输入地址。

**Tech Stack:** Python 3.12、Flask、SQLite、cryptography、Binance 官方 Python SDK、web3.py、Blockscout API、CoinGecko API、MetaMask Connect 前端适配器、pytest。

**Spec:** `docs/superpowers/specs/2026-09-27-spot-research-workbench-design.md`

## Global Constraints

- 本计划在 `2026-09-27-market-research.md` 完成后执行，沿用其 `create_app` 和本机同源保护。
- 链上只读地址，不请求助记词、私钥或签名交易。
- 首批链 ID 仅为 1、56；代币身份由链 ID 与合约地址组成。
- 无可信价格时标记“未计价”，不得以零计入总额。
- 第三方数据失败要显示失败来源与最近成功更新时间。

## Review Focus

- 两条链上同符号代币：按链和合约地址分开（Task 2）。
- Blockscout 只返回部分资产：保留已知余额并标明发现不完整（Task 2）。
- CoinGecko 缺价格或价格过期：保留数量，排除估值总额（Task 3）。
- 币安密钥权限包含提现：拒绝保存/启用（Task 1）。
- 钱包地址非法或用户切换地址：拒绝非法输入，切换后不显示旧地址资产为当前数据（Task 2/3）。
